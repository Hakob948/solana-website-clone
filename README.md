# Solana Website Clone

Multi-page React recreation of the Solana website design.
Educational project, not affiliated with Solana Foundation.

## Features
- Home page with stats, ecosystem and community sections
- Pages: Build, Network and others with working navigation
- Dropdown navigation menu (Learn, Build, Network, Community)
- Responsive dark design with gradients and animations

## Technologies
React, React Router, CSS

## How to run
npm install
npm start

Then open http://localhost:3000
